How this farm works

This dashboard is my intake, vault and queue control panel for Facebook. I can pick an agent by itself, use a solo form by itself, or use the full Facebook Intake Form for a complete farm run — all in this one place.

Plain truth: this dashboard does not by itself post to Facebook, browse Facebook, check my analytics or monetization, generate images, make reels or schedule anything when I submit a form. Those steps are done by Muse in chat after submission, using Run in Chat — the Money & Analytics Scout reads my numbers in chat too, not inside this dashboard. Nothing is auto-posted. Every post still needs my approval — my tap or my go-ahead in chat. If Facebook is signed out, Muse pauses and tells me; nobody enters my password.

The v2 run order — numbers first, vault second, create last

  • Step 1 — Money & Analytics Scout reads the numbers: my monetization, bonuses, challenges, Page insights and group growth, and hands me Today's Money Moves.
  • Step 2 — Repurpose Agent checks the Content Vault: what I already have gets used first — vault first, create second.
  • Step 3 — the other agents create only what's missing: new content only fills a gap the vault can't.

The 3 destinations — every run picks exactly ONE

  • Personal Profile (Glamorousgrammy Glowup) — daily photo, text and reel posts. Photo posts can tag Elkhart, Indiana.
  • Business Page (Animated Greetings by Glam) — the greeting series and business posts. Captions here may carry a store link.
  • The Glow Up Society (my group) — SHOWCASE by default. No buy links unless it's my own launch post or a promo thread where promo is allowed. Engagement lives here.

The 7 agents, in order

  • Agent 1 — Money & Analytics Scout: checks my profile Professional Dashboard monetization + bonuses, my Page insights, my group growth and my top posts by format. Tracks every active challenge — what it pays, the rules, the deadline, my progress. Never invents numbers. Its output is Today's Money Moves, a ranked list of what to do next.
  • Agent 2 — Repurpose Agent: searches the Content Vault FIRST, before anything new is created. Vault first, create second — new content only fills a gap the vault can't. Refreshes my winners with a new hook, a new caption or a new format: photo → story, reel → greeting, or a straight winner repost.
  • Agent 3 — Facebook Scout: finds the topic and hook from what's already winning on MY Facebook — Page insights, group comments and buyer intent, my best past posts, the season, my store catalog (glamhustlehub.com). Never invents sales numbers or prices.
  • Agent 4 — Image Agent: creates images in chat, all PNG. For Glam: starts from my REAL uploaded photo and converts it to the styled glam version — never a doll when a real photo exists, never slimmed down. Feed photos 4:5, reel/story art 9:16.
  • Agent 5 — Caption & Script Agent: hook, caption, first comment, hashtags. Captions speak to my people first (women over 40, plus-size, the overlooked) and end with a comment trigger. Reel scripts: persona voice + scene action only, never a description of the persona.
  • Agent 6 — Reel Agent: builds the reel with Muse's video tool in chat. Music LOW under the voiceover, AI label ON, returned in chat for approval. Never posts it.
  • Agent 7 — Post & Monetize Agent: checks destination, format, Post Angle, link/code in the first comment on Sell runs, Elkhart location on photo posts, AI label on reels — then hands me the exact post for my approval tap.

The 10 modes

  • 1. Daily Photo Post — my #1 organic earner. Real photo, styled glam version, 4:5, Elkhart tag.
  • 2. Daily Text Post — text only, proven style, ends with a question.
  • 3. Reel — 9:16, voiceover dominant, music low, AI label on. Reels unlock bonuses.
  • 4. Animated Greeting — Page series, one greeting a day.
  • 5. Group Launch Post — my launch in the group: offer in the post, ONE code with limited uses, claim in the comments, money comment pinned.
  • 6. Group Showcase Post — pure showcase. No link, no price. Engagement only.
  • 7. Story Boost — 9:16 story version of the day's winner.
  • 8. Analytics Check — Money Scout run: numbers, challenges, Money Moves.
  • 9. Repurpose Run — vault first: pick a saved asset, refresh it, queue it.
  • 10. 30-Day Plan — builds the full month calendar across all 3 destinations from the Content Vault first, day by day, flags the gaps that need new content, and ends with a short production list. Planning only — nothing posts or schedules itself; each post still needs my approval.

The Post Angle rule — either / or, never both

Every run saves ONE Post Angle, right after Mode:

  • Showcase: "Showcase only. No buy link, no price. End with a comment trigger and let the comments do the work."
  • Sell: "Sell it. The caption carries the value, the first comment carries the store link and code, and the call to action tells them exactly what to tap."

Never both in one post. If a run needs both, showcase first and sell later — two separate posts.

How Run in Chat works

Every Queue item has a Run in Chat button. It sets that item to working and opens a card with the full details and the persona's slot thumbnails. Copy the prompt from that card, paste it into chat, and Muse runs that exact run — nothing swapped. There is no scheduled pickup. My existing daily Facebook schedules are separate; this dashboard does not touch them.

Queue status buttons only change the label — queued, working or done. Changing a status does not post, browse, generate or schedule anything.

Post Tracker

The Post Tracker tab is my log of what is coming and what already went out — Upcoming on one side, Posted on the other. It is a tracker only: it does not post, schedule, or check Facebook by itself. Muse updates it in chat after posts go out, and I can add rows myself.
